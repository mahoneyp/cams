This is a fork of [Cams](https://github.com/vladpen/cams) with updated code to auto-hide the top and bottom bars when viewing a single camera in fullscreen for older versions of Android like my Fire HD 10 tablet running Android 9.<br>
Also forced SURFACE_FILL and Center-crop so it fills the whole screen.
